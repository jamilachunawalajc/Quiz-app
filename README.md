# Quiz App

A simple and interactive quiz application built using **HTML, CSS, and JavaScript**.
The app allows users to answer multiple-choice questions, navigate through the quiz, and view their final score.

## Features

* Multiple-choice questions
* Next-question navigation
* Score calculation
* Final score display
* Interactive and responsive user interface
* Simple and clean design

## Technologies Used

* **HTML5** – Structure of the application
* **CSS3** – Styling and layout
* **JavaScript** – Quiz logic, question handling, navigation, and score calculation

## How It Works

1. The user starts the quiz.
2. A question with multiple options is displayed.
3. The user selects an answer and moves to the next question.
4. The application keeps track of the user's score.
5. After all questions are completed, the final score is displayed.

## How to Run

1. Clone this repository.
2. Open the project folder.
3. Open `index.html` in your browser.

Or, if using VS Code, open the project with **Live Server**.
